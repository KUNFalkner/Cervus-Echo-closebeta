# 快速开始指南

## 项目概述

鹿鸣回音社区是一个匿名校园社交平台，让学生在安全的环境中表达自己。

## 技术栈

- **前端**: React + Vite
- **后端**: Python + FastAPI
- **数据库**: SQLite
- **UI风格**: Apple极简 + 液态玻璃效果

## 启动步骤

### 1. 启动后端服务

```bash
cd "E:\mimo code 帖子设计\backend"
pip install -r requirements.txt
python init_db.py
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

后端服务将运行在: http://localhost:8000

### 2. 启动前端服务

```bash
cd "E:\mimo code 帖子设计\frontend"
npm install
npm run dev
```

前端服务将运行在: http://localhost:5173

### 3. 访问应用

打开浏览器访问: http://localhost:5173

## 常见问题

### Q: 如何重置数据库？
A: 删除 `backend/cervus.db` 文件，然后重新运行 `python init_db.py`

### Q: 如何添加新的API端点？
A: 在 `backend/app/api/` 目录下创建新的路由文件，然后在 `main.py` 中引入

### Q: 如何修改UI主题？
A: 修改 `frontend/src/App.css` 中的颜色变量
